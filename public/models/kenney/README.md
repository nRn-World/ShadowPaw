# Kenney CC0 models

These files are selected from Kenney's CC0 3D asset library and are used by
Shadow Paw's neon-city stage and shop studio. The source commit, license
terms, selected files and intended modifications are recorded in the repository
root at [`ASSET_LICENSES.md`](../../../ASSET_LICENSES.md).

The original archive license notice is retained as `LICENSE.txt`. Credit to
Kenney and kenney.nl is included in the UI even though CC0 does not require it.
